  부활** — 전부 대표가 명시적으로 없애기로 한 것.
- **음원 사용 근거를 "저작권 확보 완료"·"상업적 사용권 확보" 류로 과장 표기하는 것.**

  작업은 아니지만, 그렇게 되면 포털이 깨진다 — 다른 세션에 넘길 때 주의).

## 폰트 — SRI 금지와 서브셋

- **외부 CDN 리소스에 SRI(`integrity`)를 절대 다시 시도하지 말 것.** 2026-08-23에
  jsdelivr가 해당 URL에 **요청마다 바이트가 다른 응답**을 줘서(파일 내 주석 한 줄의 대소문자가
  요청마다 바뀜, curl 연속 두 번 받아 diff로 실측 확인) SRI 해시를 넣자마자 프로덕션 폰트
  로드가 전면 차단되는 장애가 났다. Google Fonts도 UA별 응답이 달라 원천적으로 불가하며,
  이 사이트는 Google Fonts를 아예 쓰지 않는다. 지금은 Pretendard를 자가호스팅하므로 해당
  사항이 없어야 정상이다.
- **Pretendard는 pyftsubset으로 서브셋돼 있다**(5개 굵기 합쳐 3.94MB → 약 65~70KB).
  화면에 새 글자가 추가되면 서브셋에 없어 시스템 폰트로 조용히 폴백되므로 재서브셋이
  필요하다. 재서브셋 방법은 `public/assets/fonts/pretendard/pretendard.css` 상단 주석.
  (첫 서브셋 때 HTML/JS 주석 텍스트까지 "사용 글자"로 잡는 버그가 있었고, 그 과정에서
  원문자 `ⓒ`가 Pretendard에 아예 없는 글자라는 것도 발견해 표준 `©`로 교체했다.)

## 반딧불이 — 대표가 직접 정한 값

**200개**(2026-08-26에 100→150→200 두 단계로 대표가 직접 증량), 경로 애니메이션 3종
(`mote-drift`/`-b`/`-c`) 균등 순환, **delay는 각 입자 자신의 dur에 비례해서** 뽑는다.

원래는 애니메이션 1종에 delay가 dur와 무관한 고정 범위였는데, 대표가 라이브 화면에서
"같은 시기에 우르르 올라갔다 내려온다"고 지적해 위상을 흩어지게 바꿨다. **delay를 dur에
비례시키지 않고 고정 범위로 뽑으면** 주기가 짧은 입자들이 한 바퀴를 여러 번 돌아 결국 다시
비슷한 위상끼리 뭉친다 — 이 방식으로 되돌리지 말 것.

## CSP — 지키는 대상이 바뀐 것이지 없어진 게 아니다

`script-src`는 2026-09-08부터 `'self'`다. 리액트 전환으로 스크립트가 전부 외부 파일로
빠져 인라인 스크립트가 남지 않았고, 해시를 맞출 대상 자체가 사라졌다(그 전 이력:
2026-08-25 첫 시도 실패 → 2026-09-01에 원인 규명 후 재적용 — `<script>` 태그 바로 뒤 첫
줄바꿈까지 포함해 해시해야 한다는 것).

**검사는 없애지 않고 지키는 대상을 바꿨다**: `scripts/check-inline-script.py`가 산출물에
인라인 `<script>`가 생기면 CI를 실패시킨다 — `'self'`만으로는 인라인 스크립트가 **조용히**
차단되기 때문이다(예전 해시 불일치와 똑같은 증상). `style-src`의 `'unsafe-inline'`은
유지해야 한다: 반딧불이가 입자마다 인라인 CSS 변수를 설정한다.

## 소리 — 두 번 뒤집힌 결정이라 배경까지 남긴다

**지금 사양(2026-09-09 대표 확정)**: 방문하면 **소리가 난다.** 볼륨은 0에서 50%까지
부드럽게 올라오고, 음소거를 껐다 켜면 **직전 값**으로(55%였으면 55%로) 부드럽게
돌아온다. 볼륨바도 그 흐름을 따라 움직인다.

- **2026-08-31 (`3c8a48e`)**: 대표가 "소리가 저절로 나온다"고 지적 → `audio.muted = true`를
  강제해 **항상 음소거로 시작**하게 바꿨다. 브라우저 자동재생 정책이 방문 이력에 따라
  달라져서 사람마다 소리가 나기도 안 나기도 하는 게 이유였다.
- **2026-09-09**: 대표가 이 결정을 **직접 뒤집었다** — "사람이 의도적으로 주소를 치거나
  북마크된 걸 눌러서 들어갈 땐 무조건 소리가 나야 돼. 50% 볼륨으로 해서 시작해."

그래서 **"음소거로 시작하는 게 맞지 않나"라고 되돌리지 말 것.** 이미 한 번 그쪽이었고
대표가 뒤집은 상태다.

구현에서 지켜야 하는 것:

- **`audio.muted`를 쓰지 않는다.** 소리는 `volume` 하나로만 다루고, 음소거 = volume 0이다.
  둘을 같이 쓰면 "조용함"의 출처가 둘이 되어(muted=true인데 volume은 0.5) 볼륨바가 실제
  상태와 어긋난다.
- **볼륨 토글 판정은 순간값이 아니라 페이드가 향하는 값으로 한다.** 0으로 내려가는 도중에
  다시 누르면 순간값(0.004)을 보고 "아직 소리가 있다"로 잘못 읽어서 직전 볼륨이 그 찰나의
  값으로 덮인다(실제로 겪음).
- **자동재생이 정책으로 거부되면**(첫 방문자에게 흔하다) 페이지 안에서의 아무 조작에나
  재생을 시작하되, **앱 카드를 눌러 바깥으로 나가는 클릭은 제외한다.** 과거 사고가 정확히
  이것이다 — 카드가 새 탭으로 열리는 동시에 방금 떠난 원래 탭에서 음악이 터졌다.
  `tests/autoplay-blocked.spec.js`가 이 예외를 회귀 테스트로 고정하고 있다.
- 플레이어 컨트롤(재생·볼륨·음소거)은 전역 조작 리스너보다 **먼저** 판단해야 한다.
  안 그러면 음소거를 눌렀는데 전역 리스너가 곧바로 재생을 걸어 사용자의 조작을 덮어쓴다.

## 자주 틀리는 것
(헌법의 "이력"이 아니라, 실제로 두 번 이상 반복된 함정 목록)

- **`backdrop-filter`를 표준 속성 먼저, `-webkit-` 접두사판을 나중에 쓰는 것.**
  순서가 그러면 빌드 미니파이어가 표준 속성을 지우고 접두사판만 남기는데, 현대 크롬은
  접두사판을 적용하지 않아 **블러가 조용히 사라진다.** 반드시 `-webkit-`을 먼저,
  표준을 나중에. (2026-09-08 리액트 전환 중 실제로 겪었고, 스크린샷 비교가 잡았다.)
- **CSS 소스 순서에 기대는 것.** 같은 선택자·같은 속성이면 파일에서 나중에 나오는
  규칙이 이긴다 — 앞엣것이 매칭되는 `@media` 안에 있어도 마찬가지다. 전환 전에는 이
  성질에 기대어 모바일 override를 특정 위치에 끼워넣는 구조였고, 그 때문에 규칙이
  조용히 무시되는 사고가 두 번 났다(`.app`/`.player-mobile`, `.desc .short`).
  지금은 **한 CSS 파일이 한 컴포넌트의 클래스를 전부 소유하고, 반응형 규칙도 그 파일
  안에 둔다**는 규칙으로 순서 의존을 없앴다 — 같은 클래스를 두 파일에서 손대지 말 것.
- **폰트 서브셋 재생성을 빠뜨림.** 새 문구를 추가하면 서브셋에 없는 글자가 시스템
  폰트로 조용히 폴백된다. 검사 대상 글자는 **렌더된 DOM**에서 뽑는다 — 소스를 훑으면
  코드 식별자까지 사용 글자로 잡히기 때문이다. (전환 전 검사는 정적 HTML만 봐서
  곡 길이 표시 `2:05`의 숫자가 빠진 걸 못 잡고 있었다.)
- **화면에 안 보이는 값을 다른 값에서 조립하는 것.** 카드 썸네일의 대체 텍스트(alt)를
  카드 제목에서 조립했다가, QUIZ TOGETHER만 "같이교육 퀴즈 미리보기"에서
  "QUIZ TOGETHER 미리보기"로 바뀐 채 배포된 적이 있다(2026-09-08, 감사에서 발견).
  **화면에 그려지지 않는 값이라 스크린샷 비교도 computed style 대조도 못 잡는다.**
  대체 텍스트·aria-label 같은 값은 데이터에 그대로 두고 그대로 쓸 것. 지금은
  `tests/locked-geometry.spec.js`가 여섯 개 값을 문자열로 고정한다.
- **테스트 서버가 검증하려는 것을 실제로 지원하는지 확인하지 않는 것.** 테스트 서버를
  파이썬 내장 서버로 쓰던 동안 **HTTP Range를 지원하지 않아 오디오가 아예 탐색 불가**
  (`audio.seekable`이 비어 있어 `currentTime` 설정이 조용히 무시됨)였고, 그래서 탐색
  동작을 바꿔놓고도 검증할 수단이 없었다(2026-09-09 발견). 지금은 `vite preview`를
  쓴다 — Range를 지원하고(206 Partial Content 실측) 배포 산출물을 그대로 서빙한다.
  `--host 127.0.0.1`은 유지할 것(넓게 열면 테스트 도는 동안 산출물이 외부에 노출된다).
- **화면이 바뀌지 않았는지 확인하지 않고 리팩터링하는 것.** 큰 변경 전에
  `npm run test:visual -- --update-snapshots`로 기준선을 만들어두고, 변경 후 비교한다.
  `tests/locked-geometry.spec.js`는 수치로도 같이 지킨다.
- **지시를 넘겨짚어 문장을 새로 짓는 것.** 문구 수정 지시는 받은 그대로만 반영한다.
