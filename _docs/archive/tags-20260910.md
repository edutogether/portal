## 실행 방법(2단계 승인 후)

```bash
git tag "refs/archive/tags/<원래이름>" "<원래이름>"
git push origin "refs/archive/tags/<원래이름>"
git push origin ":refs/tags/<원래이름>"   # 원래 태그 삭제 — GitHub 룰셋이 꺼진 뒤에만 가능
git tag -d "<원래이름>"                    # 로컬에서도 원래 이름 제거
```
